# VisaAI / VizaOson — план по слоям

Полное видение продукта записано в переписке (MASTER PROJECT BIBLE) — это
итоговая цель через несколько лет, а не то, что строится за одну сессию.
Ниже — реальный порядок реализации, от дешёвого/быстрого к дорогому/долгому.
Идём по порядку, не перепрыгивая и не переделывая пройденное без причины.

## Статус

- ✅ **Слой 0 — Лендинг.** Живой сайт VizaOson: hero, направления
  (Шенген/США/UK/ОАЭ), форма заявки. https://vizaoson-site-production.up.railway.app
- ✅ **Слой 1 — Реальный приём заявок.** Форма на сайте сохраняет заявки в
  Postgres (`app.py`, таблица `visa_leads`). Проверено локально и через
  независимый запрос к БД. Есть `/api/leads?token=...` для просмотра
  (ADMIN_TOKEN сгенерирован и лежит в переменных окружения сервиса).

## Дальше по порядку

- ⬜ **Слой 2 — Чек-листы по странам.** Статические данные (без ИИ/OCR):
  для каждой страны/типа визы — список документов текстом. Дёшево, не
  требует ИИ, сразу повышает ценность сайта.
- ⬜ **Слой 3 — Уведомления о заявке.** Когда приходит заявка — сообщение в
  Telegram (боту/группе), чтобы не проверять `/api/leads` руками.
- ⬜ **Слой 4 — Личный кабинет (минимальный).** Регистрация, вход, статус
  своей заявки — без загрузки документов пока.
- ⬜ **Слой 5 — Загрузка документов + хранение.** Без ИИ-анализа — просто
  загрузить и увидеть список у себя в кабинете.
- ⬜ **Слой 6 — AI/OCR.** Распознавание паспорта, проверка фото, проверка
  документов. Дорогой и долгий слой — начинать только когда есть реальные
  пользователи и понятно, что именно им нужно автоматизировать в первую
  очередь.
- ⬜ **Слой 7+ — Интеграции.** Страхование, авиабилеты, переводы, White
  Label, CRM, мобильные приложения — из MASTER PROJECT BIBLE, по мере
  роста и только под реальный спрос/платящих клиентов.

## Принцип

Каждый слой — рабочий и проверенный (задеплоен, протестирован вживую),
прежде чем переходить к следующему. Не пишем документацию на 800+ страниц
вместо кода — специфика следующего слоя уточняется перед его реализацией,
не заранее на 5 слоёв вперёд.
